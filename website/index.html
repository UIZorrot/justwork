不是又一个
文档工具。

JustWork 把协作对象从“文件”扩展到完整工作上下文：结构、权限、历史和 Agent 都围绕同一个加密工作区运行。

01 / ENCRYPTION

密码掌握在你手里

内容先在客户端加密，再同步到后端。工作区密码不会写入后端数据库；选择“记住密码”时，只保存在当前浏览器设备。

02 / COLLABORATION

实时，而且可追溯

多人进入同一工作区协作，保存状态、成员在线状态与操作历史清晰可见；历史是追加记录，不提供改写历史的 rebase。

03 / AGENT-NATIVE

Agent 是参与者，不是外挂

从侧栏复制连接说明给 Agent。它通过同一后端 API 读写工作区，并在历史里留下可识别的操作归因。

04 / STRUCTURE

一种空间，四种表达

长文写 Markdown，数据放 Table 或 Sheet，流程与项目进入 Board。文件夹、置顶和垃圾箱构成统一的信息结构。

05 / RECOVERY

撤销、恢复、找得回来

从操作历史回滚内容，从垃圾箱恢复误删项目。重要更改不需要靠记忆和运气。

06 / OWNERSHIP

数据库也可以是你的

付费工作区可选连接你自己的 PostgreSQL。它不是必填项；留空即可使用 JustWork 托管存储。

三步进入工作。

无需账号体系和复杂邀请流程。创建者建立工作区，把 ID 与密码安全地交给协作者，即可开始。

01

打开 JustWork

使用网页版，或从 Chrome 商店 / ZIP 安装扩展。

02

创建加密工作区

设置名称与工作区密码。妥善保存密码，它无法由服务端找回。

03

邀请人类与 Agent

共享工作区凭据；需要 Agent 时，从工作区侧栏复制专用连接说明。
