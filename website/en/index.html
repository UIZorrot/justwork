More than
another doc tool.

JustWork expands collaboration from files to the full working context. Structure, access, history, and agents all operate around one encrypted workspace.

01 / ENCRYPTION

You hold the password

Content is encrypted on the client before it reaches the backend. The workspace password is never written to the backend database; remembering it stores it only on the current browser device.

02 / COLLABORATION

Real-time and traceable

People work together in the same workspace with visible save status, presence, and activity history. History is append-only and cannot be rewritten with rebase.

03 / AGENT-NATIVE

Agents are participants

Copy connection instructions from the sidebar. An agent reads and writes through the same backend API, with identifiable attribution in workspace history.

04 / STRUCTURE

One space, four formats

Write long-form content in Markdown, keep data in Table or Sheet, and move projects through Board. Folders, pins, and trash create one information structure.

05 / RECOVERY

Undo, restore, recover

Roll supported content back from activity history and recover mistakenly deleted items from trash. Important changes do not depend on memory or luck.

06 / OWNERSHIP

Your database, optionally

Paid workspaces may connect to your own PostgreSQL database. It is entirely optional; leave it blank to use JustWork-managed storage.

From zero to work
in three steps.

No account system or complicated invitation flow. A creator makes the workspace and securely shares its ID and password with collaborators.
