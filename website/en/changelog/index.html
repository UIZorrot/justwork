Changelog.

JustWork feature updates from 0.0.1 through 0.0.9.

Versions0.0.90.0.80.0.70.0.60.0.50.0.40.0.30.0.20.0.1

0.0.9 Current

  • Fixed idle pages overwriting or reverting documents
  • Improved history rollback and document-load protection
  • Improved real-time collaboration, WebSocket reconnection, and corrupted-document isolation
  • Added the web app, product site, and Chinese and English documentation

0.0.8

  • Added the web workbench
  • Added password changes for workspace creators
  • Improved Table, Sheet, and Board real-time sync
  • Improved collaboration and reconnection stability

0.0.7

  • Completed paid-workspace storage and history quotas
  • Completed Chinese and English interfaces
  • Improved collaboration sync

0.0.6

  • Added paid workspaces
  • Added document history and rollback
  • Added edit-conflict merging
  • Added custom document ordering

0.0.5

  • Improved Markdown real-time collaboration
  • Preserved unsynced edits across refreshes, document switches, and disconnects

0.0.4

  • No user-facing feature changes

0.0.3

  • Added the workspace mention inbox
  • Added member names and the member list
  • Improved refresh, offline replay, and save-conflict handling
  • Improved agent connections

0.0.2

  • Added Markdown real-time collaboration
  • Added Table, Sheet, and Board
  • Added image sync, folders, and trash

0.0.1

  • Added encrypted workspace creation and unlock
  • Added Markdown editing and local offline saves
  • Added the Agent API, CLI, and local bridge
