Quick start

  1. Open the JustWork web app, or install the Chrome extension.
  2. Enter a workspace name and password, choose a free or paid workspace, and create it.
  3. Create Markdown, Table, Sheet, Board content, or a folder.
  4. When you need collaborators, send the workspace ID and password through a secure channel.

Keep the workspace password.The backend does not store the plaintext password and cannot recover it. Losing it may make workspace content impossible to decrypt.

Install the Chrome extension

Option 1: Chrome Web Store

Open the Chrome Web Store ↗ and select “Add to Chrome.” This is the recommended option and receives store updates automatically.

Option 2: install the ZIP

  1. Download the latest ZIP and extract it to a permanent folder.
  2. Open chrome://extensions in the address bar.
  3. Enable “Developer mode.”
  4. Select “Load unpacked,” then choose the extracted folder.
  5. Pin JustWork from the extensions menu and select its icon to open it.

Manual installations do not update automatically. Download the new ZIP, replace the extracted files, and reload the extension when updating.

Workspace and password

Workspace IDLocates the hosted workspace and may be shared with collaborators. It is not the decryption key.
Workspace passwordUnlocks and encrypts content. Share it only through a trusted channel.

Remember password

If “Remember password on this device” is enabled, the password is stored only in this browser's local storage. Do not enable it on public or shared devices.

Change password

Only the workspace creator may change the password. A warning is shown first; after the change, every existing member except the creator is removed and must enter again with the new password.

Offline state

When the connection drops, the interface shows an offline or pending state. Do not close every window before the status is “Saved.” After reconnecting, wait for the save status to settle before leaving.

Content types

MarkdownLong-form writing, plans, meeting notes, and mixed-format content.
TableCards and records described with fields, similar to a lightweight database.
SheetGrid data, batch entry, and structured calculations.
BoardTask flows, project states, and kanban collaboration.

Use folders to organize content and pin frequent items. Deleted items first go to trash instead of disappearing permanently.

Collaboration

  1. Copy the workspace ID from workspace information.
  2. Send the password through a separate secure channel. Avoid publishing the ID and password together.
  3. The collaborator opens JustWork and unlocks the existing workspace with its ID and password.
  4. Choose a display name so presence and activity records are identifiable.

Changes to the same content sync in real time. “Saving” means operations still await confirmation; “Saved” means the server has acknowledged the current queue.

Connect an AI agent

An agent participates through the open JustWork Backend API, not by connecting directly to the database.

  1. Open “Connect Agent” in the workspace sidebar.
  2. Review the generated setup text containing the backend URL, workspace ID, and, when allowed, the password.
  3. Copy it to an agent you trust.
  4. The agent reads the JustWork Agent Skill before searching, creating, or modifying workspace content.

Minimize password exposure.Give the workspace password only to agents you trust and limit the assigned task. Changing the workspace password later invalidates other members and old credentials.

History, undo, and recovery

Workspace history is append-only: new changes create new events and past events are not rewritten with rebase. Open activity history to review events and roll back supported content.

  • Free workspaces retain 200 history events by default.
  • Paid workspaces retain up to 1,000 history events.
  • Items in trash may be restored; permanent deletion cannot be undone.
  • A rollback is itself a new traceable operation.

Paid workspaces

Paid workspaces do not count toward the five-free-workspace limit and may be created as needed. They provide four times the hosted storage of a free workspace and retain up to 1,000 history events.

Custom PostgreSQL (optional)

You may enter your own PostgreSQL connection while creating a paid workspace. This is entirely optional; leave it blank for JustWork-managed storage. A self-hosted database is not subject to JustWork's hosted storage limit, while history remains capped at 1,000 events. Database capacity and charges are determined by its provider.

Connection information is submitted only after payment and stored encrypted with a backend routing key. It is not placed in Stripe metadata.

Troubleshooting

It keeps showing “Saving”

Check the connection indicator and network. Keep the page open until it changes to “Saved.” If it remains pending, copy critical edits to a temporary backup before refreshing.

Content disappears and returns

This usually indicates the local view is reconnecting to collaborative state. Avoid repeated refreshes or editing in multiple offline tabs; after the network recovers, keep one main editing tab.

The workspace will not unlock

Check the complete workspace ID, password capitalization, and whether the creator recently changed the password. Old members must enter again with the new password after a change.

The ZIP will not load

Select the extracted folder whose root contains manifest.json, not the ZIP file itself.
