从开始到协作。

安装、创建、编辑、邀请成员，以及把 Agent 接入同一个加密工作区。

适用于 JustWork v0.0.9
目录快速开始安装扩展工作区与密码内容类型多人协作连接 Agent历史与恢复付费工作区故障排查

快速开始

  1. 打开 JustWork 在线版，或安装 Chrome 扩展。
  2. 输入工作区名称与密码，选择免费或付费工作区，然后创建。
  3. 新建 Markdown、Table、Sheet、Board 或文件夹，开始编辑。
  4. 需要协作时，将工作区 ID 和密码通过安全渠道发给协作者。

请保存工作区密码。后端不会保存明文密码，因此无法替你找回。忘记密码可能导致你无法解密工作区内容。

安装 Chrome 扩展

方法一：Chrome Web Store

打开 Chrome Web Store ↗，点击“添加至 Chrome”。这是推荐方式，可自动接收商店更新。

方法二：直接安装 ZIP

  1. 下载最新 ZIP 并解压到一个固定文件夹。
  2. 在地址栏打开 chrome://extensions。
  3. 打开右上角“开发者模式”。
  4. 点击“加载已解压的扩展程序”，选择刚才解压的文件夹。
  5. 从浏览器扩展菜单固定 JustWork，并点击图标打开。

手动安装不会自动更新。更新时请下载新 ZIP、覆盖解压目录，然后在扩展管理页点击刷新。

工作区与密码

工作区 ID定位云端工作区，可分享给协作者，本身不是解密密钥。
工作区密码用于解锁和加密内容。只通过可信渠道分享。

记住密码

选中“在此设备上记住密码”后，密码只保存在当前浏览器的本地存储中。公共或共用设备上不要启用此选项。

修改密码

只有工作区创建者可以修改密码。操作前会明确提示；修改完成后，除创建者外的现有成员都会被移出，需要使用新密码重新进入。

离线状态

网络中断时，界面会显示离线或待同步状态。不要在未确认“已保存”前关闭所有窗口。恢复连接后，等待保存状态稳定再离开。

内容类型

Markdown适合长文、方案、会议记录和混合格式内容。
Table适合以字段描述卡片、记录或轻量数据库式信息。
Sheet适合网格数据、批量录入和结构化计算场景。
Board适合任务流、项目状态和看板式协作。

使用文件夹组织内容，置顶高频项目；删除的内容先进入垃圾箱，不会立即永久消失。

多人协作

  1. 在工作区信息中复制工作区 ID。
  2. 通过另一个安全渠道发送工作区密码，不建议把 ID 与密码公开放在同一处。
  3. 协作者打开 JustWork，使用已有工作区 ID 与密码解锁。
  4. 为自己设置昵称，便于在线成员和操作记录识别。

同一内容的更改会实时同步。界面显示“保存中”时代表仍有待确认操作；显示“已保存”才表示服务端已确认当前队列。

连接 AI Agent

Agent 通过 JustWork Backend 的开放接口参与工作区，而不是直接连接数据库。

  1. 打开工作区侧栏中的“连接 Agent”。
  2. 检查生成的设置文本，其中包含后端地址、工作区 ID，以及在允许时提供的密码。
  3. 复制设置文本并发送给你信任的 Agent。
  4. Agent 会先读取 JustWork 的 Agent Skill，再执行检索、创建或修改操作。

密码最小暴露。只把工作区密码交给你信任的 Agent，并限制其任务范围。结束后可修改工作区密码，使其他成员和旧凭据失效。

历史、撤销与恢复

工作区操作历史采用追加记录：新的修改会产生新事件，不会通过 rebase 等方式重写过去。打开“操作历史”可查看事件，并对支持的内容执行回滚。

  • 免费工作区默认保留 200 条历史事件。
  • 付费工作区保留最多 1000 条历史事件。
  • 垃圾箱中的内容可以恢复；彻底删除无法撤销。
  • 回滚本身也是一次新的可追溯操作。

付费工作区

付费工作区不计入 5 个免费工作区的数量限制，可按需创建。默认提供免费工作区 4 倍的托管存储空间，并保留最多 1000 条历史事件。

自定义 PostgreSQL（可选）

创建付费工作区时可以填写自己的 PostgreSQL 连接；这完全是可选功能。留空时使用 JustWork 托管存储。使用自有数据库时不受 JustWork 托管空间限制，但历史记录仍最多保留 1000 条；数据库本身的容量和费用由数据库提供方决定。

数据库连接信息只在付款完成后提交，并由后端路由密钥加密保存，不会放入 Stripe metadata。

故障排查

一直显示“保存中”

先检查顶部连接状态和网络。保持页面开启，等它转为“已保存”。若持续不变，刷新前先复制正在编辑的关键内容作为临时备份。

内容暂时消失或重新出现

这通常表示本地视图正在与远端协作状态重新连接。不要连续刷新或在多个离线标签页里覆盖编辑；确认网络恢复后，只保留一个主编辑标签。

无法解锁

检查工作区 ID 是否完整、密码大小写是否正确，以及创建者是否刚修改过密码。密码修改后，旧成员必须用新密码重新进入。

ZIP 无法加载

确认你选择的是“解压后的文件夹”，并且该目录根部能看到 manifest.json。不要直接选择 ZIP 文件。
